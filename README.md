# DCEA_tutorial
Supporting data and R source files for the execution of an R tutorial for conducting DCEA

This repository provides supporting data and R scripts as part of a tutorial. The tutorial (available as a Quarto file from the publisher) provides steps and R code for developing a microsimulation model parameterized using a large secondary dataset, and demonstrates the evaluation of equity - using direct equity-weighting - alongside traditional cost-effectiveness metrics

The user must first set-up an R project before adding these files and executing the Quarto file.
